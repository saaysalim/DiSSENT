System Architecture

End-to-end architecture showing exchange between MiCT and The Liberties Dublin systems.

→ request
securecomm Gateway localhost:8081 (System A)
→ commit
Fabric Ledger chaincode state + proof
The Liberties Dublin libertiesdublin.ie
← response
securecomm2 Gateway localhost:8082 (System B)
← event
Kafka Brokers exchange topics on 9092 / 9093
